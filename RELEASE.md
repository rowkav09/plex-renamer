# Release & Distribution Guide

> ⏸️ **For Later:** This guide is for when you're ready to make your project public.
> For setting up your private repository now, see [QUICK_START_PRIVATE.md](QUICK_START_PRIVATE.md)

This guide explains how to release Plex Renamer on GitHub and make it available to users.

## Step 1: Initialize Git Repository

```bash
# Navigate to your project directory
cd r:/media/tv

# Initialize git
git init

# Add all files
git add .

# Create initial commit
git commit -m "Initial commit: Plex Renamer v1.0"

# View your changes (optional)
git log --oneline
```

### Git Status Check
```bash
git status
```

Should show everything committed with no uncommitted changes.

---

## Step 2: Create GitHub Repository

1. Go to https://github.com/new
2. Create new repository named `plex-renamer`
3. DO NOT initialize with README (you already have one)
4. Copy the repository URL (HTTPS or SSH)

### Connect Local Repo to GitHub

```bash
# Add GitHub as remote
git remote add origin https://github.com/YOUR_USERNAME/plex-renamer.git

# Verify remote
git remote -v

# Push to GitHub
git branch -M main
git push -u origin main
```

---

## Step 3: Create Release on GitHub

### Manual Release Process

1. **Create a version tag locally:**
   ```bash
   git tag -a v1.0.0 -m "Release version 1.0.0"
   git push origin v1.0.0
   ```

2. **On GitHub:**
   - Go to https://github.com/YOUR_USERNAME/plex-renamer/releases
   - Click "Draft a new release"
   - Select tag "v1.0.0"
   - Title: "Plex Renamer v1.0.0"
   - Description: Copy from CHANGELOG/NEWS section
   - Attach assets (see below)

### Release Assets to Attach

**For GitHub Releases (recommended for your use case):**

1. **Source code (auto-generated by GitHub)**
   - ZIP file of entire repo
   - TAR.GZ file of entire repo

2. **Optional: Standalone Executable**
   - See "Building Executables" section
   - Usually: `plex-renamer-v1.0.0-windows.exe`

3. **Optional: PyPI Package**
   - See "Uploading to PyPI" section

## Recommended Release Strategy: GitHub Releases Only

Since you chose GitHub Releases as your primary distribution method, here's the recommended workflow:

### Release Checklist

- [ ] Update version in `pyproject.toml`
- [ ] Update version in `setup.py`
- [ ] Update `CHANGELOG.md` with release notes
- [ ] Test locally: `python plex_renamer.py`
- [ ] Run basic smoke tests
- [ ] Create git tag: `git tag -a vX.Y.Z -m "Release vX.Y.Z"`
- [ ] Push tag: `git push origin vX.Y.Z`
- [ ] Create GitHub Release from tag
- [ ] Add release notes
- [ ] Upload any assets (executables, etc.)

### Version Numbering (Semantic Versioning)

Use format: `vMAJOR.MINOR.PATCH`

Examples:
- `v1.0.0` - Initial stable release
- `v1.1.0` - New feature added
- `v1.0.1` - Bug fix
- `v2.0.0` - Breaking changes

## Advanced: Building Standalone Executable

To create a `.exe` file for Windows users (no Python needed):

### Using PyInstaller

```bash
# Install PyInstaller
pip install pyinstaller

# Build executable
pyinstaller --onefile --name plex-renamer plex_renamer.py

# Output: dist/plex-renamer.exe
```

### Include Additional Files
```bash
pyinstaller --onefile \
    --name "plex-renamer" \
    --add-data "README.md:." \
    --add-data "LICENSE:." \
    --add-data "config.example.json:." \
    plex_renamer.py
```

Then upload `dist/plex-renamer.exe` to GitHub Releases.

## GitHub Actions for CI/CD (Optional)

Create `.github/workflows/release.yml`:

```yaml
name: Release

on:
  push:
    tags:
      - 'v*'

jobs:
  release:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v2
      
      - name: Set up Python
        uses: actions/setup-python@v2
        with:
          python-version: '3.10'
      
      - name: Install dependencies
        run: |
          python -m pip install --upgrade pip
          pip install build twine
      
      - name: Build
        run: python -m build
      
      - name: Create GitHub Release
        uses: actions/create-release@v1
        env:
          GITHUB_TOKEN: ${{ secrets.GITHUB_TOKEN }}
        with:
          tag_name: ${{ github.ref }}
          release_name: Release ${{ github.ref }}
```

## First Release Checklist

### Before Creating Release

```bash
# 1. Update versions
# Edit pyproject.toml, setup.py, add version string

# 2. Create changelog
# Create CHANGELOG.md with release notes

# 3. Final commit
git add .
git commit -m "chore: Prepare v1.0.0 release"

# 4. Create tag
git tag -a v1.0.0 -m "Release version 1.0.0 - Initial stable release"

# 5. Push to GitHub
git push origin main
git push origin v1.0.0
```

### On GitHub Website

1. Navigate to **Releases** tab
2. Click **Draft a new release**
3. Select tag: `v1.0.0`
4. Title: `Plex Renamer v1.0.0 - Initial Release`
5. Description (example):

```markdown
## Features
- Progress bars with Rich UI
- Complete undo/restore system
- Fuzzy show detection
- Multi-episode file support
- Plex-perfect folder structure

## Installation
Download the source ZIP and extract, or:
```bash
git clone https://github.com/username/plex-renamer.git
python plex_renamer.py
```

## Requirements
- Python 3.7+
- Internet connection (for TVMaze API)

## Changelog
- Initial stable release
- All core features implemented
```

6. (Optional) Attach Windows executable
7. Click **Publish Release**
